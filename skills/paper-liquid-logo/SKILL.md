# Integration guidance

This is a project-authored integration skill, not a skill supplied by the upstream repository.

Source: https://github.com/paper-design/liquid-logo

Integrate @paper-design/shaders-react LiquidMetal with an authored SVG mask. Keep the readable name in HTML. Bound pixel count, stop animation for reduced motion, and release shader mounts when unmounted. Preserve the PolyForm Shield notice; do not describe the upstream project as MIT.
