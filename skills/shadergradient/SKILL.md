# Integration guidance

This is a project-authored integration skill, not a skill supplied by the upstream repository.

Source: https://github.com/ruucm/shadergradient

Use @shadergradient/react with matching Fiber and Three peers. Drive ShaderGradient with typed props. Prefer 3d lighting to avoid remote environment assets. Cap pixelDensity; use animate off for reduced motion. Keep animated materials outside long-form evidence text. Record source and package versions.
